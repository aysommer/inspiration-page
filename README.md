# inspiration-page
Browser extension for the Google Chrome.

<a href="https://inspiration-page.vercel.app/" target="_blank">Demo</a>

## Stack
Vite, Tailwind CSS 4, daisyUI 5.

## Development
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

Load the `dist` folder as an unpacked extension in `chrome://extensions`.
